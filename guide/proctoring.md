# 在线监考与防作弊

砚考把在线监考拆成三道防线：**考前核验身份、考中实时监看、考后行为回溯**。
本文说明每道防线提供了什么、该怎么配置，以及认定违纪时的操作路径。

::: tip 平衡原则
防作弊强度越高，考生的设备门槛和心理压力也越大。
建议按考试性质分档配置，而不是一律拉满 —— 见文末「推荐配置档位」。
:::

## 第一道防线：考前身份核验

| 手段 | 说明 | 强度 |
| --- | --- | --- |
| 考试码 | 6 位数字，随链接分发 | 低 |
| 账号登录 | 校验是否在参与名单内 | 中 |
| 短信验证码 | 校验预留手机号 | 中 |
| 人脸识别 | 与预留证件照或身份证信息比对 | 高 |
| 身份证号 + 姓名 | 对接权威库核验 | 高 |

**人脸核验**的工作方式：

1. 考生首次进入时拍摄正脸，与系统内底片比对，相似度 ≥ 阈值（默认 0.8）方可进入
2. 开考后按设定间隔（默认 5 分钟）随机抓拍，与底片二次比对
3. 连续 3 次比对失败 → 标记为「身份存疑」，通知监考员

::: warning 隐私与合规
人脸数据默认加密存储，可在 [系统设置](/admin/settings) 中设定留存期限（默认考后 90 天自动删除）。
开启人脸核验前，请在考试说明中明确告知考生并取得同意。
:::

## 第二道防线：考中实时监看

### 监考大屏

在考试详情页点击「监考大屏」，一屏掌握全局：

```text
┌────────────────────────────────────────────────────────┐
│  应考 248   已登录 231   已交卷 96   异常 7              │
├────────────────────────────────────────────────────────┤
│  ⚠ 异常列表                          │  考生详情         │
│  · 张同学  切屏 5 次   12:31         │  [实时画面]       │
│  · 李同学  人脸核验失败  12:28       │  行为时间轴       │
│  · 王同学  离开页面 3 分钟 12:25     │  [发送警告]       │
└────────────────────────────────────────────────────────┘
```

### 行为检测项

| 检测项 | 触发条件 | 可配置动作 |
| --- | --- | --- |
| 切屏 / 失焦 | 页面失去焦点超过 N 秒 | 记录 / 警告 / 强制交卷 |
| 离开全屏 | 退出全屏模式 | 记录 / 警告 |
| 复制粘贴 | 在答题区尝试粘贴 | 拦截 / 记录 |
| 右键与开发者工具 | 尝试打开调试面板 | 记录 / 警告 |
| 多端登录 | 同一账号在两台设备作答 | 踢出先登录端 / 警告 |
| 屏幕共享中断 | 停止共享超过 N 秒 | 警告 / 强制交卷 |
| 环境音异常 | 检测到多人语音 | 记录（供人工复核） |
| 答题速度异常 | 单题作答时间 < 阈值 | 标记待复核 |

### 屏幕共享监看

要求考生共享整个屏幕或指定窗口，监考员可实时查看。
支持「多画面墙」模式，一屏最多同时看 16 人，可轮播。

::: tip 带宽提示
每位考生的屏幕共享约占用 300 Kbps—1 Mbps 上行带宽。
50 人同时监看建议保证 50 Mbps 以上的服务端带宽。
:::

### 摄像头抓拍

独立于人脸核验的定时抓拍，用于留存影像证据。
建议间隔 3—10 分钟，重要考试可开启「随机间隔」避免考生规避。

## 第三道防线：考后行为回溯

考试结束后，在 **监考记录** 中可以按考生查看完整时间轴：

```text
12:00:00  进入考场，人脸核验通过（相似度 0.91）
12:03:12  开始作答
12:15:40  切屏（持续 8 秒）          ← 记录
12:31:02  切屏（持续 42 秒）         ← 触发警告
12:31:45  监考员发送警告
12:58:20  交卷，用时 88 分 20 秒
```

每条记录都可以展开看到**抓拍画面**与**当时的屏幕截图**。

### 作弊风险报告

系统综合各项指标给出 0—100 的**风险分**，并按分数排序：

| 风险分区间 | 建议处理 |
| --- | --- |
| 0—20 | 正常 |
| 21—50 | 人工抽检 |
| 51—80 | 逐人复核，必要时约谈 |
| 81—100 | 重点核查，结合录像确认 |

::: warning 风险分仅供参考，不能单独作为违纪认定依据
砚考只负责**记录与提示**，最终认定必须由人工结合影像证据完成。
系统不提供也不主张任何自动判定作弊的能力。
:::

### 雷同卷检测

对客观题作答序列做相似度分析：

- 计算考生之间的答案一致率
- 标记「答案序列高度一致 + 错误题目也一致」的组合
- 输出可疑组合列表供人工核查

典型误报场景：题目太少、难度过低导致大部分人全对 —— 系统会提示「样本区分度不足，结果不可靠」。

## 违纪处理流程

```text
发现异常 → 发送警告（留痕）→ 情节严重则强制收卷
                                       ↓
                              考后在监考记录中「认定违纪」
                                       ↓
                    填写违纪类型与说明 → 关联证据（截图/录像片段）
                                       ↓
                          成绩作废 → 通知考生 → 归入诚信档案
```

考生可在规定时间内**申诉**，申诉由教务处/考务负责人处理，处理结果同样留痕。

## 推荐配置档位

### 日常随堂测验

```
身份核验：考试码 + 账号登录
行为检测：仅记录切屏
屏幕共享：关闭
抓拍：关闭
```

### 期中 / 期末考试

```
身份核验：账号登录 + 人脸核验
行为检测：切屏警告（3 次）、离开全屏记录、禁止粘贴
屏幕共享：开启
抓拍：5 分钟间隔
雷同卷检测：开启
```

### 认证 / 招聘等高利害考试

```
身份核验：身份证 + 人脸核验（阈值 0.85）
行为检测：切屏 2 次即警告，5 次强制收卷
屏幕共享：强制开启，中断即警告
摄像头：强制开启，3 分钟间隔随机抓拍
环境音：开启
雷同卷检测：开启
IP / 设备限制：开启
```

## 常见问题

**考生设备没有摄像头怎么办？**
可在「防作弊」中把摄像头设为「可选」，无摄像头的考生会被标记为「无影像记录」，
由监考员决定是否允许参加。

**监考大屏卡顿？**
降低多画面墙的同时观看数量，或关闭屏幕共享实时流改为仅抓拍。

**考生反映误判切屏？**
输入法切换、系统弹窗都可能触发。可在检测项中把「切屏判定阈值」从 3 秒调到 8 秒，
并要求考生关闭无关软件的通知。
