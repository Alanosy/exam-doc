# 产品简介

砚考是一套面向高校、职业院校、政企单位与培训机构的**在线考试与题库管理平台**。
它以「题库」为数据底座，把考试业务中的出题、组卷、排考、监考、阅卷、分析串联成一条可追溯的完整链路。

## 我们解决的问题

传统考试组织方式里，这几个环节的摩擦最明显：

| 环节 | 常见痛点 | 砚考的做法 |
| --- | --- | --- |
| 题库 | 题目散落在 Word、Excel 和个人电脑里，版本混乱、重复率高 | 统一入库，按知识点 / 难度 / 标签多维组织，导入时自动查重 |
| 组卷 | 手工拼卷耗时，AB 卷难度难保证一致 | 约束驱动的自动组卷，可生成多套等效平行卷 |
| 组织 | 考生名单靠人工核对，排考冲突频发 | 组织架构与教学班同步，按班级 / 岗位批量排考 |
| 监考 | 线上考试难以确认「是不是本人、有没有作弊」 | 人脸核验 + 屏幕监看 + 行为留痕，考后可回溯复核 |
| 阅卷 | 主观题评阅标准不一，进度难追踪 | 分步骤评分、双人评阅与仲裁，进度实时可见 |
| 分析 | 只有总分，看不出学生哪里不会 | 知识点掌握度、难度区分度、错题本与个性化练习 |

## 核心特性

### 1. 结构化题库

支持单选、多选、不定项、判断、填空、简答、论述、计算、编程、材料题等十余种题型。
每道题可挂载知识点、难度系数、认知层次、使用频次与解析，支持富文本与公式（LaTeX）、图片、音频素材。

详见 [题库管理](/guide/question-bank)。

### 2. 三种组卷模式

- **固定卷**：人工挑选题目，顺序与分值完全可控，适合正式考试。
- **抽题卷**：按规则从题库随机抽题，同一场考试内所有考生题目一致。
- **随机卷**：每位考生独立抽题，题目顺序与选项顺序双重打乱，适合大规模机考。

详见 [试卷与组卷](/guide/paper)。

### 3. 严肃的在线监考

三道防线：考前身份核验、考中实时监看与异常拦截、考后行为回溯。
所有监考数据（截图、切屏记录、环境音频）按考试留存，可作为违纪认定的依据。

详见 [在线监考与防作弊](/guide/proctoring)。

### 4. 高效阅卷

客观题交卷即出分；主观题支持按步骤给分、分值细化到 0.5 分、双人独立评阅与第三人仲裁。
AI 评分建议仅作为参考，**必须由教师确认后才会生效**。

详见 [阅卷与复核](/guide/grading)。

### 5. 可落地的学情分析

从一场考试到一学期的数据都能沉淀：成绩分布、难度与区分度、知识点掌握热力图、
班级对比、个体成长曲线，支持导出 Excel / PDF 报表。

详见 [成绩与学情分析](/guide/analytics)。

### 6. 面向机构的部署形态

支持 SaaS 与**完全私有化部署**两种形态。私有化部署下所有数据留在机构自有服务器，
支持国产化软硬件环境、单点登录对接与等保合规审计日志。

详见 [私有化部署](/admin/deployment)。

## 版本形态

| 形态 | 适用对象 | 说明 |
| --- | --- | --- |
| SaaS 版 | 中小型机构、临时性考试 | 开箱即用，按考试场次或活跃人数计费 |
| 私有化标准版 | 高校、大型企业 | 部署在机构机房或专有云，支持定制域名与品牌 |
| 私有化集群版 | 万人以上规模并发 | 多节点集群、读写分离、异地容灾 |
