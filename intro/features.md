# 功能总览

砚考共有 14 个功能模块，其中 13 个已可用，1 个规划中。
功能旁的标记说明当前实现程度，避免你按文档找不到按钮。

## 题库与试题

### 题库管理

题库的增删改查与导出，支持**分类树**归类、**可见性**（私有 / 公开）与**草稿 / 正常 / 归档**三态。可在题库内直接挂载和管理试题。

对应服务：`ruoyi-exam-question` :9211 · 详见 [题库管理](/guide/question-bank)

### 试题管理

支持 9 种题型：

| 题型 | 答案模式 | 说明 |
| --- | :---: | --- |
| 单选 | `option` | 默认 4 个选项 |
| 多选 | `option` | 支持部分得分（由试卷配置） |
| 判断 | `option` | 固定「正确 / 错误」两项 |
| 填空 | `blank` | 支持多空，每空多个等价写法 |
| 简答 | `text` | 富文本参考答案 |
| 论述 | `text` | 富文本参考答案 |
| 代码 | `code` | 支持 10 种语言高亮 |
| 文件上传 | `text` | 考生上传附件作答 |
| 匹配 | `pairs` | 左项 = 右项配对 |

含富文本题干与解析、难度（easy / medium / hard）、默认分值。
**Excel 模板导入**采用整批校验、失败整批回滚并逐行提示；支持导出。

## 组卷与考试

### 试卷管理

手工选题与按规则随机抽题两种组卷方式，规则可保存复用、候选不足时给出提示。

可配：总分与及格分、题目 / 选项乱序、自动判分与人工阅卷开关、部分得分与答错扣分。

详见 [试卷与组卷](/guide/paper)

### 考试管理

正式 / 练习两类考试，配置维度最多的一个模块：

| 维度 | 配置项 |
| --- | --- |
| 时间 | 时间窗、限时、迟到入场分钟数 |
| 次数 | 允许重考及次数上限 |
| 准入 | **白名单（按部门选人）** 或 **公开链接（加入码 + 密码 + 有效期）** |
| 展示 | 答案展示时机（不展示 / 交卷后 / 考试结束后 / 立即） |
| 判分 | 客观题部分得分及比例、答错扣分 |
| 防作弊 | 9 项规则独立配置 |
| 证书 | 绑定及格证书模板 |
| 发布 | 支持保存草稿与「保存并一键发布」 |

含考试情况看板与导出。详见 [发布考试](/guide/exam)

### 监考中心

准实时监控（**10 秒静默轮询**）查看自己考试的监考会话、风险概览、事件流水与摄像头抓拍。
考生进入答题页后自动产生记录。

详见 [在线监考与防作弊](/guide/proctoring)

### 防作弊服务

检测 13 类行为。规则由考试单独配置，达到上限时**由服务端判定强制交卷**，并向考生透明展示规则与计数。

## 考后环节

### 阅卷管理

客观题交卷即自动判分（区分正确 / 半对 / 错误三态），主观题按「考试 → 答卷 → 逐题」三级人工阅卷并记录改分日志。

::: tip 双评仲裁与 AI 预评
接口已预留但尚未接入。AI 预评目前会返回「未接入」。
:::

详见 [阅卷与成绩](/guide/grading)

### 考试统计

基于预计算汇总表，每 10 分钟定时重算兜底，也可手动重算。输出：

- 大盘概览
- 分数段分布
- 考生明细与排名
- 逐题正确率 / 难度 / 区分度
- 选项分布与易错项
- 知识点掌握度与薄弱分级

支持作废答卷不入统。详见 [成绩与学情分析](/guide/analytics)

### 证书管理

考试及格后自动颁发（含主观题的卷子待阅卷完成后再发，避免分数不一致）。

- 模板支持占位符 `{nickName} {account} {examName} {score} {totalScore} {passScore} {certNo} {issueDate} {expireDate}`
- 支持印章、背景图、横竖版与有效期
- 证书墙区分「有效 / 已过期 / 已吊销」，支持打印
- 支持手工补发与吊销（吊销需填原因）

详见 [证书管理](/guide/certificate)

### 错题本

交卷后答错与半对的题目自动进入错题本。支持按来源分组查看、重练并即时判分看解析、记笔记、标记已掌握、移出与恢复，并保留每次重做的历史。

详见 [错题本](/guide/wrong-book)

### 考试记录

考生查看自己参加过的每一场考试与答卷，可按考试、类型、状态、是否及格筛选，并逐题回看自己的作答、正确答案、解析与得分。

## AI 能力

### AI 命题

智能出题、干扰项生成、试题改写扩量、知识点打标、解析生成、试题质检。
按知识点与难度批量生成，可基于参考资料命题；生成的题**默认落草稿态**，
质检未通过的单独列出，确认后才进正式题库。

### AI 阅卷

主观题 AI 预评，**给的是建议分不是最终分**，带要点命中明细与置信度。
置信度低于 0.6 的自动标记需人工确认。另有评分自检、评分校准、
代码题判分与雷同检测。

### AI 学情

错题归因（区分概念未理解 / 审题失误 / 计算错误等六类）与个性化推题。
归因结果写入长期学情画像，越用越准。

### AI 试卷与监考

试卷审查（知识点覆盖、难度分布、重复度、预计用时）与考前难度预估。
监考行为分析把事件时序整理成证据链——**不做最终作弊判定**，永远转人工。

### AI 助手

用自然语言办事：「帮我出 10 道计算机网络的选择题，放进测试题库」。
Agent 自己规划步骤、缺参数时弹卡追问、写操作前请求确认。

对应服务：`ruoyi-exam-ai` :9220 + `ruoyi-exam-agent` :9221 · 详见 [AI 功能总览](/guide/ai-overview)
