# 发布考试

一场考试 = 试卷 + 时间 + 对象 + 规则。本文讲发布考试时需要配置的每一项。

## 创建考试

进入 **考试管理 → 新建考试**，依次完成以下五组配置。

## 1. 基本信息

| 字段 | 说明 |
| --- | --- |
| 考试名称 | 考生可见，建议写清课程与场次 |
| 考试说明 | 考生进入前展示，可写携带物品、注意事项 |
| 关联试卷 | 从已有试卷中选择，或现场新建 |
| 考试类型 | 正式考试 / 随堂测验 / 练习 / 模拟考 |

`练习` 类型不计入成绩档案，适合学生自主刷题。

## 2. 时间安排

| 字段 | 说明 |
| --- | --- |
| 开放时段 | 考生可进入的时间窗口，如 `09:00 — 11:00` |
| 答题时长 | 进入后开始倒计时，如 `90 分钟` |
| 允许迟到 | 迟到后仍可进入，但答题时长不延长 |
| 提前交卷限制 | 可设定「开考 30 分钟后才允许交卷」 |

::: tip 开放时段 vs 答题时长
- **开放时段**是「大门什么时候开」，到点关闭，迟到不候（除非开启允许迟到）。
- **答题时长**是「进门后能待多久」，每位考生独立计时。

例如开放时段 09:00—11:00、答题时长 90 分钟：
考生最晚 09:30 进入才能答满 90 分钟。
:::

## 3. 参与对象

三种指定方式：

**按组织节点**：勾选班级 / 部门，节点下的成员自动获得考试资格。
适合校内期末考试，且与组织架构同步更新（转班学生自动跟随）。

**导入名单**：上传 Excel（学号/工号 + 姓名），系统按学号匹配。
适合跨班级的补考、重修考试。

**公开链接 + 考试码**：任何拿到链接的人都能参加。
适合招聘笔试、社会认证考试。可额外开启「报名审核」。

## 4. 作答规则

| 配置项 | 推荐值 | 说明 |
| --- | --- | --- |
| 题目乱序 | 大规模考试开启 | 同一大题内题目随机排列 |
| 选项乱序 | 大规模考试开启 | 单选/多选选项随机排列 |
| 逐题作答 | 简单测验开启 | 一屏一题，答完才能下一题 |
| 允许返回修改 | 正式考试开启 | 关闭后提交即不可更改 |
| 答案自动保存 | 始终开启 | 默认每 30 秒云端保存 |
| 允许使用计算器 | 视科目而定 | 客户端内嵌计算器 |
| 允许草稿纸 | 无 | 记录草稿内容供监考回溯 |

## 5. 防作弊设置

详见 [在线监考与防作弊](/guide/proctoring)，这里只列入口开关：

- 身份核验（人脸 / 考试码 / 短信）
- 切屏检测与阈值
- 屏幕共享监看
- 摄像头抓拍间隔
- 环境音频采集
- 禁止复制粘贴
- IP 限制与设备限制

## 6. 成绩设置

| 配置项 | 说明 |
| --- | --- |
| 成绩发布方式 | 自动发布 / 手动发布 / 不发布 |
| 公布解析 | 发布成绩时是否同时公布答案与解析 |
| 允许查卷 | 开放时间段内学生可申请复查 |
| 及格线 | 默认取试卷设定，可覆盖 |
| 成绩计入档案 | 关闭后仅作为过程性评价 |

## 通知与提醒

可在「通知设置」中配置自动提醒：

- 考前 1 天、考前 30 分钟 → 站内信 + 短信 / 邮件
- 考试开始时 → 站内信
- 成绩发布时 → 站内信 + 短信

模板内容可自定义，支持 `{姓名}` `{考试名称}` `{考试链接}` 等变量。

## 发布与发布后

点击「发布」后，考试进入**未开始**状态，此时：

- 考生可以看到考试信息与倒计时，但不能进入
- 你可以继续修改大部分配置
- 系统会为公开链接考试生成二维码

::: warning 考试一旦开始，以下配置不可修改
关联试卷、答题时长、题目乱序、选项乱序、防作弊策略。
如需改动，只能「中止考试」后复制一份重新发布 —— 已有作答数据不会丢失。
:::

## 特殊场景

### 补考与重修

在考试列表中找到原考试 → 「复制为补考」，系统会：
- 复用同一份试卷（或选择平行卷）
- 自动带入原考试未及格人员名单
- 成绩标记为「补考」，与正考成绩分开统计

### 缓考

在考生列表中找到该生 → 「标记缓考」。
该生不占用本次考试名额，成绩记为「缓考」而非 0 分，且不参与统计。

### 缺考与违纪

| 处理 | 操作位置 | 统计影响 |
| --- | --- | --- |
| 缺考 | 考生列表批量标记 | 记 0 分或排除，可配置 |
| 违纪 | 监考记录 → 认定违纪 | 成绩作废，记录归入诚信档案 |

### 多场次轮换

同一份试卷需要在一天内考 4 个批次时，创建**一场考试 + 4 个场次**，
而非 4 场考试。场次共享成绩统计，但各有独立的开放时段与监考大屏。

## 考试结束之后

1. 系统自动执行「强制收卷」，未交卷的考生以已保存答案为准
2. 客观题实时判分完成
3. 主观题进入 [阅卷与复核](/guide/grading)
4. 全部阅完后 [发布成绩](/guide/analytics)

## 常见问题

**考生说打不开链接？**
先确认考试是否已到开放时段，再检查是否开启了 IP 限制，最后让考生换浏览器（推荐 Chrome / Edge 最新版）。

**考生误交卷了怎么办？**
在考生列表中找到该生 → 「恢复作答」，倒计时继续，已答内容保留。

**可以延长某个考生的时间吗？**
可以。考生列表 → 「单独延时」，支持按分钟追加，系统会记录操作日志。
