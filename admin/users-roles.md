# 用户与角色

## 用户管理

### 添加用户

三种方式：

| 方式 | 场景 |
| --- | --- |
| 单个添加 | 新入职教师、临时账号 |
| Excel 批量导入 | 开学季批量建账号 |
| 系统对接自动同步 | 已有人事/教务系统 |

批量导入模板列：`姓名`、`学号/工号`、`手机号`、`邮箱`、`组织节点路径`、`角色`。

### 账号状态

```text
待激活 ──激活──▶ 正常 ──停用──▶ 已停用
                   │
                   └──锁定──▶ 已锁定（登录失败过多，自动解锁或管理员解锁）
```

- **待激活**：已导入但未登录过，可通过短信/邮件邀请
- **正常**：可正常使用
- **已停用**：保留数据但无法登录，适用于毕业/离职人员
- **已锁定**：连续 5 次密码错误自动锁定，30 分钟后自动解锁

::: tip 毕业/离职请「停用」而不是「删除」
删除用户会连带删除其考试记录与成绩（除非先做数据归档）。
正确做法是停用，数据保留用于历史统计与审计。
:::

### 登录方式

可在 [系统设置](/admin/settings) 中组合启用：

- 账号 + 密码
- 手机号 + 短信验证码
- 企业微信 / 钉钉 / 飞书扫码
- CAS / OAuth2 / SAML 单点登录
- LDAP / AD 域账号

私有化部署的机构通常对接校内统一身份认证。

## 角色与权限

### 内置角色

| 角色 | 权限摘要 |
| --- | --- |
| 超级管理员 | 全部，含系统级配置与审计日志 |
| 机构管理员 | 本机构内的组织、成员、角色、考试管理 |
| 考务管理员 | 考试发布、排期、监考、违纪处理、成绩发布 |
| 题库管理员 | 题库增删改、题目审核 |
| 教师 | 出题、组卷、阅卷、查看所授班级成绩 |
| 阅卷员 | 仅阅卷任务内的评分 |
| 监考员 | 监考大屏、发送警告、强制收卷，**不能查看成绩** |
| 学生 / 考生 | 参加考试、查看本人成绩与错题本 |
| 审计员 | 只读查看全部操作日志 |

### 权限点清单（节选）

| 模块 | 权限点 |
| --- | --- |
| 题库 | 查看 / 创建 / 编辑 / 删除 / 审核 / 授权他人 |
| 试卷 | 查看 / 创建 / 编辑 / 删除 / 导出 |
| 考试 | 查看 / 创建 / 编辑 / 发布 / 中止 / 删除 |
| 监考 | 查看大屏 / 发送警告 / 强制收卷 / 认定违纪 |
| 阅卷 | 评阅 / 复核 / 仲裁 / 查看他人评分 |
| 成绩 | 查看 / 发布 / 更正 / 导出 |
| 分析 | 查看班级 / 查看全校 / 导出报表 |
| 系统 | 成员管理 / 角色管理 / 系统设置 / 审计日志 |

### 自定义角色

内置角色不满足时可以新建角色：

1. 进入 **系统管理 → 角色管理 → 新建角色**
2. 勾选权限点（按模块分组）
3. 保存后在成员管理中授予用户

::: tip 建议：尽量少用自定义角色
自定义角色越多，后期排查「为什么这个人能看到这个数据」的成本越高。
优先复用内置角色，只在确实需要细分时（如「只能阅卷不能看成绩」）才新建。
:::

## 授权操作

### 给单个用户授权

**成员管理 → 找到用户 → 编辑角色**：
选择角色 + 数据范围（组织节点），一个用户可有多条授权记录。

### 批量授权

**成员管理 → 批量授权**：
按组织节点筛选人员，一次性授予同一角色。
适合开学季给某院系全体教师统一授权。

### 临时授权

对于短期项目（如某次认证考试的外聘阅卷员），可设置**有效期**：
到期后权限自动回收，无需人工记得取消。

## 审计

所有权限相关操作都会记录：

- 谁在什么时候给谁授予/回收了什么角色
- 谁查看了哪些敏感数据（成绩导出、监考影像）
- 登录记录（IP、设备、时间、失败原因）

审计员可在 **系统管理 → 审计日志** 中按人、按时间、按操作类型检索。
日志不可删除、不可修改，保留期可在 [系统设置](/admin/settings) 中配置。

## 常见问题

**教师看不到某个班级的成绩？**
检查其角色的数据范围是否覆盖该班级所在节点，以及是否拥有「成绩 → 查看」权限。

**监考员能看到分数吗？**
默认不能。「监考员」角色不含成绩查看权限，这是有意设计的 ——
监考与评分应当分离。

**能限制教师只看到自己出的题吗？**
可以。在角色权限中把题库的「查看」范围设为「仅本人创建」。
