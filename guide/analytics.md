# 成绩与学情分析

考试结束不是终点，数据才刚开始产生价值。本文说明砚考提供哪些分析视角，以及怎么把结论用起来。

## 四个分析层次

```text
一场考试  →  考试概览、题目质量分析
一门课程  →  多次考试趋势、知识点掌握度
一个班级  →  班级对比、薄弱环节定位
一个学生  →  个体报告、错题本、成长曲线
```

## 考试概览

进入考试详情 → 「分析报告」，默认展示：

| 指标 | 含义 |
| --- | --- |
| 应考 / 实考 / 缺考 | 出勤情况 |
| 最高分 / 最低分 / 平均分 | 集中趋势 |
| 中位数 | 比平均分更抗极值干扰 |
| 标准差 | 分数离散程度，越小说明区分度越弱 |
| 及格率 / 优秀率 | 按设定及格线与自定义优秀线 |
| 分数段分布 | 直方图，默认 10 分一段 |

### 分布形态怎么看

| 形态 | 说明 | 应对 |
| --- | --- | --- |
| 正态（中间高两边低） | 正常 | — |
| 正偏（低分扎堆） | 卷子偏难或教学未达标 | 检查题目难度与教学重点 |
| 负偏（高分扎堆） | 卷子偏易或区分度不足 | 增加中等难度题目 |
| 双峰 | 学生水平两极分化 | 考虑分层教学 |

## 题目质量分析

每一道题都会计算：

| 指标 | 定义 | 健康区间 |
| --- | --- | --- |
| 难度 P | 该题平均得分 / 该题满分 | 0.3 — 0.8 |
| 区分度 D | 高分组通过率 − 低分组通过率 | ≥ 0.3 为优秀 |
| 正确率 | 答对人数 / 作答人数 | — |
| 选项分布 | 各选项被选比例 | 干扰项应有人选 |
| 作答时长中位数 | — | 与设定建议用时比对 |

::: tip 难度与区分度的解读
- **难度 < 0.3 且区分度 < 0.2**：题目过难或表述有歧义，建议修改或淘汰
- **难度 > 0.9 且区分度 < 0.2**：题目太简单，拉不开差距
- **难度适中但区分度为负**：低分组答对比率反而更高 → **高度可疑，请检查答案是否标错**

最后一种情况务必人工核查，这是最容易暴露题库错误的信号。
:::

### 选项分析（选择题）

```text
第 7 题（难度 0.42，区分度 0.51）
  A •••••••• 12%      ← 干扰项有效
  B •••••••••••••••••••••••• 42%   ✓ 正确
  C •••••••••••••• 28%   ← 主要误选项，学生可能混淆了概念 X
  D •••••••• 16%      ← 干扰项有效
  未作答 2%
```

C 选项被选比例偏高时，报告会提示「建议针对该错误概念加强讲解」，
并可直接跳转到对应知识点下的错题集。

## 知识点掌握度

这是砚考分析模块最有价值的部分。

### 班级热力图

```text
知识点          掌握度   趋势
力学/牛顿定律    82%  ████████░░  ↑
力学/动量守恒    54%  █████░░░░░  ↓
电磁学/安培环路  61%  ██████░░░░  →
热学/熵增        77%  ███████░░░  ↑
```

掌握度 = 该知识点下所有题目的**加权得分率**（按分值加权）。
趋势对比的是上一次同类考试。

点击任意知识点 → 自动筛选出「该知识点答错的学生名单」，
可直接用于分组辅导或布置针对性作业。

### 个体知识点诊断

单个学生视角：

- 各知识点掌握度雷达图
- 与班级平均的对比
- 「已掌握 / 需巩固 / 未掌握」三档分类
- 推荐练习：自动从题库抽取该知识点下未做过的同难度题目

## 班级与群体对比

选择多个班级（或院系、部门）后可对比：

| 对比维度 | 呈现方式 |
| --- | --- |
| 平均分、及格率 | 横向柱状图 |
| 分数段分布 | 堆叠直方图 |
| 知识点掌握度 | 多班雷达图 |
| 进步幅度 | 折线图（多次考试） |

支持按教师、按班级、按生源地等任意字段分组对比。

## 个体报告

单个学生的完整报告包含：

1. **本次考试**：总分、班级排名、百分位、各题得分
2. **错题本**：所有答错题目 + 正确答案 + 解析 + 知识点标签
3. **知识点诊断**：掌握度雷达图与薄弱点提示
4. **成长曲线**：历次考试成绩变化趋势
5. **作答行为**：用时分布、修改次数（可选展示）

学生端在「我的报告」中查看，教师端可查看全班所有人。

## 错题本与针对性练习

错题本自动按知识点归类，支持：

- 学生自主重做（不计入成绩）
- 教师一键「布置错题重练」：系统抽取同知识点、同难度的**不同题目**组成练习卷
- 导出打印

::: tip 把错题变成教学资源
连续多次考试中错误率 > 50% 的知识点，建议在教研室例会上讨论。
砚考的「知识点错误率排行」可以直接作为教研选题依据。
:::

## 报表导出

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| Excel（成绩单） | 学生 × 题目明细 / 汇总 | 教务存档、二次加工 |
| PDF（班级报告） | 图表 + 结论文字 | 汇报、家长会 |
| PDF（个人报告） | 个体报告 | 发给学生 / 家长 |
| CSV | 原始数据 | 对接数据仓库 |

导出操作会记入审计日志。

## 数据对接

成绩数据可通过以下方式流出砚考：

- **定时推送**：按日/周推送到指定接口，见 [Webhook 与集成](/api/webhook)
- **主动查询**：调用 [开放 API](/api/) 拉取
- **文件交换**：定时生成 Excel 到指定目录（私有化部署）
- **教务系统同步**：支持与主流教务系统做成绩回写（需实施配置）

## 常见问题

**为什么分析里没有某道题的数据？**
该题所在考试尚未发布成绩，或该题作答人数为 0（全员缺考）。

**区分度显示「—」？**
计算区分度需要足够样本（默认 ≥ 30 人），样本不足时不计算。

**能修改历史成绩后再看分析吗？**
可以。成绩更正后分析报告会自动重算，并标注数据版本。
