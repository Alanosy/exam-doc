# 试卷与组卷

组卷是把题目按规则组织成一张可施测的卷子。砚考提供三种模式，覆盖从「完全人工把控」到「全自动生成」的不同需求。

## 三种模式对比

| 模式 | 选题方式 | 考生同卷性 | 适用 |
| --- | --- | --- | --- |
| 固定卷 | 人工挑题 | 完全一致 | 期末考试、认证考试 |
| 抽题卷 | 规则抽取，生成后固定 | 同场次一致 | 期中测验、月考 |
| 随机卷 | 规则抽取，逐人生成 | 每人不同 | 大规模机考、招聘笔试 |

## 固定卷

适合对题目顺序、分值设置要求严格的正式考试。

### 操作流程

1. **试卷管理 → 新建试卷 → 固定卷**
2. 填写基本信息：试卷名称、总分、建议时长、及格线
3. 点击「添加题目」：
   - 从题库按知识点 / 题型 / 难度筛选后勾选
   - 或直接输入题号批量添加
4. 在右侧「试卷结构」面板中：
   - 拖动调整题目顺序
   - 修改每题分值（默认取题库建议分值）
   - 添加**大题分区**（如「一、选择题（共 20 分）」）
5. 点击「预览」以考生视角检查排版
6. 保存

### 大题分区

固定卷支持两级结构：**大题 → 小题**。

```text
一、单项选择题（每小题 2 分，共 20 分）
    1. ……
    2. ……
二、填空题（每空 2 分，共 20 分）
    11. ……
三、计算题（每题 15 分，共 30 分）
    21. ……
```

大题可独立设置：标题、说明文字、分值规则、是否乱序。

## 抽题卷与随机卷

两者都用**约束规则**驱动选题，区别只在生成时机：
抽题卷在你点击「生成」时生成一份，所有考生共用；
随机卷在每位考生开考时独立生成一份。

### 规则配置

进入「规则组卷」面板，按题型逐个添加规则条目：

| 配置项 | 说明 |
| --- | --- |
| 题型 | 单选 / 多选 / 填空 / 计算 …… |
| 题目数量 | 该题型抽几道 |
| 单题分值 | 该题型每题几分 |
| 知识点范围 | 限定从哪些知识点抽题 |
| 知识点配比 | 如 `力学 40% / 电磁学 60%` |
| 难度范围 | 如 0.4—0.8 |
| 平均难度 | 该组题目的目标平均难度 |
| 排除题目 | 排除近 N 次考试已用过的题 |
| 排除知识点 | 不考的知识点 |

### 示例：一场大学物理期中测验

```yaml
总分: 100
时长: 90 分钟
规则:
  - 题型: 单选题
    数量: 10
    分值: 3
    知识点配比: {力学: 50%, 电磁学: 50%}
    难度范围: [0.5, 0.9]
  - 题型: 填空题
    数量: 5
    分值: 4
    知识点配比: {力学: 40%, 电磁学: 60%}
    难度范围: [0.4, 0.8]
  - 题型: 计算题
    数量: 2
    分值: 15
    知识点: 力学
    难度范围: [0.3, 0.6]
    排除: 近 2 次考试已用
约束:
  平均难度目标: 0.65 ± 0.05
  同一知识点最多重复: 2 次
```

点击「试生成」可以预览生成结果，不满意就调整规则再来一次。

::: tip 规则太紧会生成失败
如果提示「无可行解」，通常是**题目池太小**或**约束互相冲突**。
排查顺序：放宽难度范围 → 扩大知识点范围 → 降低平均难度精度 → 补充题库。
:::

### 平行卷（AB 卷）

在抽题卷模式下点击「生成多套平行卷」，可以指定套数（如 3 套）与
**套间重复率上限**（如 20%）。系统会保证各套卷：

- 总分、题型结构、平均难度一致（误差 ≤ 0.05）
- 知识点覆盖一致
- 题目重合度不超过设定上限

适用于需要 A/B 卷防相邻抄袭的考场场景。

## 选项与题目乱序

三种模式都可开启：

- **题目乱序**：同一大题内题目随机排列
- **选项乱序**：单选题/多选题的选项随机排列（判断题与填空题不适用）

::: warning 不要在固定卷上开启乱序后再人工核对答案
乱序是考生端生效的行为，教师端预览看到的仍是原始顺序。
导出的 Word 纸质卷若需与机考一致，请在导出时选择「按第一套乱序结果导出」。
:::

## 分值与时长的自动测算

组卷面板顶部会实时显示：

| 指标 | 计算方式 |
| --- | --- |
| 总分 | 各题分值之和 |
| 预估用时 | 各题建议用时之和 × 1.15（留缓冲） |
| 平均难度 | 按分值加权的难度系数均值 |
| 难度分布 | 各难度区间题目分值占比 |

若预估用时与设定的考试时长相差超过 20%，系统会给出提醒。

## 试卷的复用与版本

- 一份试卷可被多场考试引用，例如同一份卷用于两个教学班
- 修改试卷会生成新版本，**已开始的考试不受影响**
- 「复制试卷」可快速基于已有试卷创建变体

## 导出

| 格式 | 用途 |
| --- | --- |
| Word | 打印纸质卷、存档 |
| PDF | 直接分发 |
| Excel | 二次编辑 |
| JSON | 系统间迁移 |

导出时可选择是否包含答案与解析。
