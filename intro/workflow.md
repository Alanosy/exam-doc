# 核心流程

砚考把「一场考试」拆成 8 个环节。这张图值得先记住，后面每个功能文档都是它的某个局部。

## 全景流程图

```text
① 建题库 ──▶ ② 出题 ──▶ ③ 组卷 ──▶ ④ 发布考试
                                        │
                                        ▼
⑧ 错题巩固 ◀── ⑦ 发证 ◀── ⑥ 出统计 ◀── ⑤ 考试 + 监考 + 阅卷
```

对应的服务与主要负责人：

| 环节 | 负责人 | 服务 | 端口 |
| :---: | --- | --- | :---: |
| ① 建题库 | 教师 | `exam-question` | 9211 |
| ② 出题 | 教师 | `exam-question` | 9211 |
| ③ 组卷 | 教师 | `exam-paper` | 9212 |
| ④ 发布考试 | 教师 | `exam-manage` | 9213 |
| ⑤ 答题 / 监考 | 学生 | `exam-answer` + `exam-proctor` | 9214 / 9219 |
| ⑥ 阅卷 | 教师 | `exam-mark` | 9215 |
| ⑦ 发证 + 统计 | 系统 | `exam-cert` + `exam-stat` | 9218 / 9216 |
| ⑧ 错题巩固 | 学生 | `exam-practice` | 9217 |

## 数据是怎么流转的

```text
question ──┐
           ├──▶ paper ──▶ manage ──▶ answer ──┬──▶ mark ──▶ answer(回写成绩)
           │                                   ├──▶ proctor
           │                                   ├──▶ practice
           │                                   └──▶ cert
           └──────────────────────────────────────▶ stat（旁路只读）
```

三个值得注意的设计：

**① 开考时抓试卷快照**

`answer` 在开考瞬间把试卷结构一次性拉到本地。此后老师改卷子，不会影响正在答题的考生——否则会出现「同一场考试题目不一致」的严重事故。

**② 成绩只有一处写入口**

客观题由 `answer` 自动判分；主观题由 `mark` 算完后调 `answer.writeBackMark` 回写。
**其它服务不允许直接改 `exam_record` 的成绩字段**。排查成绩异常只需盯这一条链路。

**③ 统计是旁路的**

`stat` 不写任何业务数据，靠影子实体（`QuestionRef`、`ExamRef`）在本地做映射，避免跨库 JOIN。
它既有定时重算（每 10 分钟），也支持手动立即重算。

## 一场考试的状态流转

```text
not_start  未开始
    │  （保存并发布）
    ▼
ongoing    进行中  ──▶ 考生可在时间窗内入场答题
    │  （时间窗结束 / 手动结束）
    ▼
finished   已结束  ──▶ 阅卷、统计、发证
    │  （归档）
    ▼
archived   已归档
```

考生答卷 `exam_record` 也有自己的状态：`answering` 答题中 → `submitted` 已交卷 / `expired` 已过期。

## 时间线样例

假设一场 90 分钟的期末考试：

```text
T-3天   教师：发布考试，生成加入链接/白名单选人
T-0    管理员：开启网关限流，确认防作弊与摄像头可用
T+0    学生：扫码加入 → 阅读考试须知 → 开始答题
       系统：开始作答后创建 proctor session，摄像头按 60s 抓拍
T+90   系统：倒计时归零，前端主动提交 + 后端 ExamTimeoutTask 兜底双保险
       系统：客观题即时出分；主观题生成阅卷任务
T+91   系统：答错/半对题写入错题本；及格判定，无待阅主观题则颁发证书
T+120  教师：主观题阅卷，逐题打分（每次改分写审计日志）
T+130  系统：触发统计重算，生成成绩报表
```

## 异常情况下会怎样

| 意外 | 系统行为 |
| --- | --- |
| 考生刷新页面 | 断点续答，已保存答案不丢；防作弊计数由心跳从服务端同步回来 |
| 断网 | 答案已逐题保存；恢复后可继续 |
| 倒计时归零未提交 | 前端主动提交 + 后端定时任务兜底，**双保险** |
| 重复点击交卷 | 幂等，只产生一条成绩 |
| 作弊次数超限 | **服务端**判定并强制交卷，前端无法绕过 |
| 本机时间被篡改 | `useServerClock` 校准服务端时钟，倒计时以服务端为准 |
| 主观题未阅完 | 延后发证，避免证书成绩与最终成绩不一致 |
