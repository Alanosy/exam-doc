# 发布考试

考试管理是配置项最多的模块。对应后端服务 `ruoyi-exam-manage` :9213。

::: tip 前置条件
需要一张状态为「就绪」的试卷。见 [试卷与组卷](/guide/paper)。
:::

## 两步表单

**考试管理 → 新增**，分两步。

## 第一步：基本信息

| 字段 | 说明 |
| --- | --- |
| 考试名称 | 考生看到的名字 |
| **考试类型** | 正式（`1`）/ 练习（`2`） |
| 关联试卷 | 只能选「就绪」状态的卷子 |
| 开始时间 / 结束时间 | **时间窗**——什么时候可以入场 |
| **限时** | 单个考生可以答多久（分钟） |
| 允许迟到 | 开 + 迟到分钟数 |
| 允许重考 | 开 + 重考次数上限 |
| 及格证书 | 绑定的证书模板，为空则不发 |

::: warning 时间窗 vs 限时，别搞混
| | 时间窗 | 限时 |
| --- | --- | --- |
| 控制什么 | 什么时候能来考 | 能答多久 |
| 不设置 | 考试的起止时刻 | 单个考生的答题时长 |

例：时间窗 09:00-11:00，限时 90 分钟。
考生 10:30 入场，他的倒计时从 10:30 开始算 90 分钟，**会在 12:00 交卷，超出时间窗**。
系统允许他答完，这是设计如此——时间窗控制的是「能不能进来」，不是「必须几点交」。
:::

::: tip 练习考试可以不设时间窗
练习类型的考试，起止时间允许为空，做成「长期有效」的练习入口。
:::

## 第二步：参加方式

这是最重要的一组配置。两种准入方式二选一。

### 方式一：白名单（按部门选人）

适合**考生名单确定**的场景——期末考试、内部考核、上岗认证。

操作：从组织架构里勾选部门或直接选人（`UserSelect` 组件，支持搜索与全选）。

- 只有名单内的人能在考试中心看到这场考试
- 支持查看/调整已选考生名单
- **发布前会强制校验：白名单不能为空**

### 方式二：公开链接（加入码 + 密码 + 有效期）

适合**名单不确定**的场景——社招笔试、外部认证、公开招募。

| 要素 | 说明 |
| --- | --- |
| 加入码 | 10 位，系统自动生成，可刷新重生成 |
| 参与密码 | 6 位，防止拿到链接的人随便进 |
| 有效期 | 可以设成到期自动失效 |

发布了以后，在列表页点「复制加入链接」，发给考生即可。
考生打开链接 → 输码或扫码 → 加入 → 答题。

::: tip 加入码为什么没有 0/1/I/O/l
字符集刻意剔除了肉眼容易混淆的字符（`0`、`1`、`I`、`O`、`l`）。
考生手抄、电话沟通时不容易出错。
:::

### 对比表

| | 白名单 | 公开链接 |
| --- | --- | --- |
| 名单确定 | ✅ | ❌ |
| 可直接扫码进 | ❌ | ✅ |
| 需要考生账号 | 是 | 是 |
| 适合 | 校内 / 内部考试 | 社招 / 外部认证 |
| 防扩散 | 强 | 靠密码 + 有效期 |

## 考试规则

### 答案展示时机

| 值 | 效果 |
| --- | --- |
| `none` | 从不展示 |
| `after_submit` | **交卷后**立刻看到答案与解析 |
| `after_exam` | 考试结束后（所有人答完或时间窗结束） |
| `immediate` | 答完一题立刻看（练习用） |

::: tip 练习选 after_submit
练习型考试建议设 `after_submit`，让考试变成学习闭环。
正式考试通常设 `after_exam` 或 `none`。
:::

### 客观题部分得分

| 字段 | 说明 |
| --- | --- |
| `partial_score` | 是否允许多选题漏选得部分分 |
| `partial_score_rate` | 得分比例，典型 0.5 |

### 防作弊配置

9 项规则在项目里单独配置，详见 [在线监考与防作弊](/guide/proctoring)。

默认值偏向「只记录、不强制」：

```ts
{ switchScreen: 0, copyPaste: 1, camera: 0, fullScreen: 0,
  cameraInterval: 60, maxPaste: 0, maxExitFullscreen: 0, devtool: 1, multitab: 1 }
```

`0` 表示不设上限（只记录不强制），**要真正拦住必须显式设阈值**。

## 保存与发布

| 按钮 | 行为 | 状态变为 |
| --- | --- | --- |
| 保存 | 存为草稿 | `not_start` |
| **保存并发布** | 立即开放 | `ongoing` |

::: danger 白名单考试的发布校验
白名单方式下，「保存并发布」会**强制校验已选考生名单**，
没选人会直接拦下来——避免出现「发布了但没人能参加」。
:::

## 考试情况看板

发布后可以在列表页点「考试情况」进入，看到：

| 指标 | 说明 |
| --- | --- |
| 应考人数 / 实考人数 | 白名单 vs 实际开考 |
| 已交卷 / 答题中 | 实时状态 |
| 及格人数 / 及格率 | |
| 平均分 | |
| **待阅卷数** | 有主观题未阅完的答卷数，会标红提醒 |
| 最高分 / 最低分 | |

支持导出考试情况明细。

## 考试邀请记录

公开链接方式的考试，每个加入的考生会产生一条 `exam_invite` 记录，可在「邀请记录」里查看谁通过什么方式、什么时候加入的。

## 常见问题

### 发布了但考生看不到

按顺序排查：

1. 考试状态是不是 `ongoing`（`not_start` 的考试考生看不到）
2. 当前时间是不是在时间窗内
3. 白名单方式下，考生是不是真的被选进去了
4. 考生的账号是不是有「考试中心」的菜单权限

### 想改已发布考试的配置

大部分字段可以改，但有约束：

| 改什么 | 有没有人答题时的区别 |
| --- | --- |
| 基本信息（名称、描述） | 随时可改 |
| 时间窗 | 随时可改 |
| **关联试卷** | 已有人开考则不建议改（快照已抓） |
| 防作弊规则 | 已开考的会话用旧规则，新会话用新规则 |

### 如何取消/终止一场考试

把状态改回草稿或手动结束。已经作答的答卷数据仍会保留。
