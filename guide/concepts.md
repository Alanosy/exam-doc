# 核心概念

砚考有 6 个核心实体。理清它们的关系，后面所有操作都不会迷路。

## 实体关系图

```text
题库 question_bank
  │ 1 : N
  ▼
试题 question ──┬── 选项 question_option
                └── 标签

试题  N : N  试卷 paper        （通过 paper_question 关联）
试卷  1 : N  考试 exam
考试  1 : N  答卷 exam_record
答卷  1 : N  作答明细 exam_answer
答卷  1 : 1  阅卷任务 exam_mark_task
考试  1 : 1  统计汇总 stat_exam_summary
答卷  N : M  错题 wrong_question
考试  1 : 1  证书模板 exam_certificate
答卷  1 : 1  证书记录 exam_certificate_record
答卷  1 : 1  监考会话 exam_proctor_session
```

## 题库（Question Bank）

**长期资产**，用来组织和管理题目。

| 属性 | 取值 | 说明 |
| --- | --- | --- |
| 可见性 | 私有 / 公开 | 公开题库同事也能引用 |
| 状态 | 草稿 / 正常 / 归档 | 归档后不再参与抽题 |
| 分类 | 树形 | 支持无限层级 |

::: tip 题库分类怎么设计
常见做法：按学科 → 章节 → 知识点，或者按岗位 → 技能项。
**分类是树形的**，拖拽即可调整归属。
:::

## 试题（Question）

**可复用的最小单位**。一道题可以同时属于多个试卷。

### 9 种题型

| 题型 | 答案模式 | 判分 | 说明 |
| --- | :---: | :---: | --- |
| 单选 `SINGLE` | 选项 | 自动 | 默认 4 选项 |
| 多选 `MULTIPLE` | 选项 | 自动 | 可配部分得分 |
| 判断 `JUDGE` | 选项 | 自动 | 固定「正确 / 错误」 |
| 填空 `BLANK` | 填空数组 | 自动 | 支持多空，每空多个等价写法 |
| 简答 `SHORT_ANSWER` | 文本 | 人工 | 富文本 |
| 论述 `ESSAY` | 文本 | 人工 | 富文本 |
| 代码 `CODE` | 代码 | 人工 | 支持 10 种语言高亮 |
| 文件上传 `UPLOAD_FILE` | 文本 | 人工 | 考生传附件 |
| 匹配 `MATCH` | 配对 | 人工 | 左项 = 右项 |

### 三个关键属性

| 属性 | 取值 | 作用 |
| --- | --- | --- |
| 难度 | `easy` / `medium` / `hard` | 随机抽题规则的筛选条件；统计里算难度系数 |
| 默认分值 | 数字 | 加入试卷时的默认分，可单卷调整 |
| 知识点 | 标签 | 知识点掌握度分析的数据源 |

::: warning 不要随意改已发布考试里的题
开考时 `answer` 服务会抓**试卷快照**，所以改题不会影响正在进行的考试。
但如果考试还没开始，改题会生效——这可能导致同一场考试不同时间入场的考生看到不同的题。
**发布前请确认题库稳定。**
:::

## 试卷（Paper）

**题目的一次编排**，可复用的模板。

```text
一张试卷 = 若干道题（有序）+ 分值表 + 判分策略
```

同一张试卷可以发布成多场考试，各自独立统计。

| 属性 | 说明 |
| --- | --- |
| 总分 | 可手动调整，不必等于题目分值之和 |
| 及格分 | 决定是否发证书 |
| 题目乱序 | 每个学生看到的题目顺序不同 |
| 选项乱序 | 每个学生看到的选项顺序不同 |
| 自动判分 | 关掉则全部走人工阅卷 |
| 部分得分 | 多选题答不全时给部分分，可配比例 |
| 答错扣分 | 答错倒扣分 |

## 考试（Exam）

**试卷 + 时间 + 人 + 规则** 的一次性活动。

### 状态流转

```text
not_start  未开始
    │  保存并发布
    ▼
ongoing    进行中
    │  时间窗结束 / 手动结束
    ▼
finished   已结束
    │  归档
    ▼
archived   已归档
```

### 两个容易搞混的概念

| 概念 | 是什么 | 举例 |
| --- | --- | --- |
| **时间窗** | 考试开放的起止时间 | 6 月 20 日 09:00 - 11:00 |
| **限时** | 单个考生可以答多久 | 90 分钟 |

考生必须在时间窗内入场并开始答题，一旦开始，倒计时按「限时」走。

**举例**：时间窗是 09:00-11:00，限时 90 分钟。
考生 10:30 才入场，他的倒计时是 90 分钟，会在 12:00 被强制交卷——**超出了时间窗**。系统会允许他答完，这是设计如此。

## 答卷（Exam Record）

一名考生参加一场考试产生的**一条记录**。

### 状态

```text
answering   答题中
    │
    ├──▶ submitted   已交卷（主动提交 / 超时自动提交 / 违规强制提交）
    └──▶ expired     已过期（时间窗结束仍未交卷）
```

### 三个判分结果

客观题不是简单对错，而是三态：

| 结果 | 含义 | 是否进错题本 |
| --- | :---: | :---: |
| 正确 | 完全答对 | ❌ |
| **半对** | 多选题漏选、填空部分空 | ✅ |
| 错误 | 完全答错 | ✅ |

::: tip 为什么要有「半对」
多选题漏选说明「知道但不全」，和完全不知道是两回事。
它们都进错题本，但可以做不同的统计分析。
:::

## 错题（Wrong Question）

交卷后由系统**自动收录**，不需要手工操作。它有独立的生命周期：

```text
未掌握 ──▶ 重练 ──▶ 已掌握 / 已忽略
              │
              └── 每次重做留一条 review 记录
```

与「题库里的题」是**引用关系**——错题本记的是「谁错了哪道题」，不复制题目本身。

| 让 A 班明天上午考 | 考试 |
