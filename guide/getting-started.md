# 快速开始

本文带你在十分钟内走完一场完整考试：**建题库 → 组卷 → 发布 → 作答 → 看成绩**。

::: tip 前提
你需要一个砚考管理员账号。若还没有，请联系机构管理员在
[用户与角色](/admin/users-roles) 中为你开通。
:::

## 第一步：创建题库

1. 左侧导航进入 **题库管理 → 我的题库**，点击「新建题库」。
2. 填写题库名称（如 `2026 春 · 大学物理 A`）、选择学科与适用学段。
3. 建议同时建立**知识点目录**。知识点是后面自动组卷与学情分析的基础，
   可以从模板导入，也可以手工录入。

```text
大学物理 A
├── 力学
│   ├── 牛顿运动定律
│   └── 动量与能量
├── 电磁学
└── 热学
```

## 第二步：录入题目

进入题库后点击「添加题目」，逐道录入；也可以走批量通道：

- **模板导入**：下载 Excel 模板，按列填写后上传，系统会校验格式并预览。
- **文本批量导入**：按约定语法一次性粘贴几十道题，适合从旧系统迁移。

每道题建议补齐这些信息，它们会在后续环节反复用到：

| 字段 | 作用 |
| --- | --- |
| 题型 | 决定判分方式 |
| 知识点 | 组卷覆盖率约束、学情分析维度 |
| 难度系数 | 组卷平均难度控制、区分度计算 |
| 解析 | 考后对学生公布，错题本直接引用 |
| 分值 / 建议用时 | 组卷时自动测算总分与时长 |

详情见 [题库管理](/guide/question-bank)。

## 第三步：组卷

进入 **试卷管理 → 新建试卷**，选择模式：

- 第一次使用建议选**固定卷**，手动挑 20 道题，心里有底。
- 熟悉之后改用**抽题卷**：设定「单选 10 题 / 填空 5 题 / 计算 2 题，
  平均难度 0.6，力学与电磁学各占 50%」，系统自动完成选题。

组好卷之后务必点「预览」，用考生视角过一遍题干排版与公式渲染。

详情见 [试卷与组卷](/guide/paper)。

## 第四步：发布考试

进入 **考试管理 → 新建考试**，关键配置项：

| 配置项 | 建议值（首次） |
| --- | --- |
| 考试名称 | `大学物理 A · 期中测验` |
| 关联试卷 | 上一步创建的试卷 |
| 考试时间 | 90 分钟 |
| 开放时段 | 2026-04-10 09:00 — 11:00 |
| 参与对象 | 按教学班选择，或导入考生名单 |
| 防作弊 | 开启「人脸核验 + 切屏警告」，其余保持默认 |
| 成绩发布 | 提交后手动发布（先阅卷再放分） |

保存后点击「发布」，系统会生成**考试链接**与**考试码**。
把链接或二维码发给考生即可。

详情见 [发布考试](/guide/exam)。

## 第五步：考生作答

考生用浏览器打开链接，流程是：

```text
输入考试码 → 身份验证 → 阅读考场规则并签署承诺 → 开始作答 → 交卷
```

作答期间答案**每 30 秒自动云端保存**，断网重连后继续，无需重做。
剩余 5 分钟、1 分钟时会有醒目提示。

## 第六步：监考

考试进行中打开 **监考大屏**，可以看到：

- 应考 / 已登录 / 已交卷人数实时刷新
- 异常考生列表（切屏、离开页面、人脸核验失败）
- 单个考生的实时画面与行为时间轴

发现异常可发送警告；情节严重时可执行「强制收卷」，系统会自动留痕。

详情见 [在线监考与防作弊](/guide/proctoring)。

## 第七步：阅卷与发布成绩

客观题在交卷瞬间已自动判完。主观题进入 **阅卷中心** 分配给你或教研组：

1. 选择「按题评阅」模式，同一道题连续批改，标准更容易保持一致。
2. 遇到争议卷点击「标记待复核」，交给仲裁人处理。
3. 全部阅完后回到考试详情，点击「发布成绩」。

详情见 [阅卷与复核](/guide/grading)。

## 第八步：看分析报告

成绩发布后进入 **学情分析**：

- **概览**：平均分、最高最低分、及格率、标准差、分数段直方图
- **题目分析**：每道题的正确率、难度、区分度，识别异常题目
- **知识点分析**：班级知识点掌握热力图，定位薄弱点
- **个体报告**：单个学生的错题本与知识点诊断

详情见 [成绩与学情分析](/guide/analytics)。
