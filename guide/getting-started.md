# 快速开始

假设你已经[部署好砚考](/backend/quickstart/requirements)并能用教师账号登录。下面用最短路径走完一遍完整闭环。

## 第 1 步：建一个题库

进入 **题库管理 → 新增**：

| 字段 | 填什么 |
| --- | --- |
| 题库名称 | 例如「前端基础」 |
| 分类 | 从题库分类树里选（需先在「题库分类」里建） |
| 可见性 | 私有（只有自己能看）/ 公开（同事也能用） |
| 状态 | 草稿 / 正常 / 归档 |

::: tip 为什么要题库
题目必须挂在题库里。题库是长期资产，分类树可以按学科、章节、岗位任意组织。
建好一次，后面所有考试都能复用。
:::

## 第 2 步：加几道题

在题库列表点「试题」进入该题库，然后新增试题。建议先各加一道，感受一下题型差异：

| 题型 | 适合测什么 | 判分方式 |
| --- | --- | --- |
| 单选 | 概念辨析 | 自动 |
| 多选 | 全面掌握 | 自动（可配部分得分） |
| 判断 | 基础认知 | 自动 |
| 填空 | 精确记忆 | 自动（支持多等价写法） |
| 简答 / 论述 | 理解与表达 | 人工阅卷 |
| 代码 | 编码能力 | 人工阅卷 |
| 匹配 | 对应关系 | 人工阅卷 |

题干中涉及公式、图片的地方用**富文本编辑器**（Quill）。

::: tip 批量加题用 Excel
几百道题不要手工加。**下载模板 → 按格式填 → 上传**，整批校验、失败整批回滚。
模板里有 7 条格式说明（比如判断填「正确/错误」、填空用 `|` 与 `;` 分隔），第一次用务必先看。
详情见 [题库与试题](/guide/question-bank#excel-批量导入)。
:::

## 第 3 步：组一张卷子

进入 **试卷管理 → 新增**，两种组卷方式二选一：

**手工选题** —— 你知道要考哪几道题时用。支持跨分页勾选、拖拽排序、批量改分值。

**随机抽题** —— 想每个学生卷子不一样时用。配一条规则：

```text
从 [前端基础题库] 中，抽取 [单选题] ，难度 [中等] ，共 [5] 道，每题 [4] 分
```

可以加多条规则，规则能保存复用。**候选不足时会提前提示**，不会开考时才发现题目不够。

组卷后填写：

| 字段 | 说明 |
| --- | --- |
| 总分 | 可手动调整（默认按题目分值累加） |
| 及格分 | 影响是否发证书 |
| 题目乱序 | 每个学生看到不同顺序 |
| 选项乱序 | 每个学生看到不同选项顺序 |
| 自动判分 | 关闭则全部题走人工阅卷 |
| 部分得分 | 多选题答不全时给部分分（可配比例） |
| 答错扣分 | 答错倒扣分（慎用） |

## 第 4 步：发布考试

进入 **考试管理 → 新增**，两步表单：

**第一步：基本信息**

考试名称、考试类型（正式 / 练习）、关联试卷、起止时间、限时分钟数、是否允许迟到及迟到分钟数、是否允许重考及次数、及格证书。

**第二步：参加方式与规则**

::: tip 两种准入方式怎么选
| 方式 | 适合 |
| --- | --- |
| **白名单（按部门选人）** | 内部考试，考生名单确定（如期末考试） |
| **公开链接（加入码 + 密码 + 有效期）** | 外部招聘、社招，名单不确定（扫码即进） |

加入码是 10 位，字符集刻意避开了 `0/1/I/O/l` 这些肉眼容易看错的字符。
:::

配置完点「**保存并发布**」，考试状态从 `not_start` 变为 `ongoing`。

发布后可以在列表里「复制加入链接」发给考生。

## 第 5 步：学生答题

用学生账号登录，进入 **考试中心**，或通过加入链接直接进入。

```text
① 阅读考试须知（展示规则、时长、防作弊说明）
② 点击「开始答题」
③ 答题：逐题自动保存，可标记「待复查」
④ 倒计时归零自动交卷，也可提前手动交卷
⑤ 客观题即时出分
```

::: warning 切屏会被记下来
答题页会显示「您已切屏 N 次 / 上限 M 次」。这不是吓唬人——
**计数和强制交卷判定都在服务端**，改浏览器 JS 没用。
:::

## 第 6 步：回看答卷

考试结束后，学生在 **考试记录** 里可以看到自己的每一场考试，逐题回看：
自己的作答、正确答案、解析、得分。

答错和半对的题会自动进入 [错题本](/guide/wrong-book)。

## 第 7 步：教师阅卷

如果卷子里有主观题，进入 **阅卷管理**：

```text
阅卷管理 → 选择考试 → 答卷列表 → 进入某份答卷 → 逐题打分 → 完成阅卷
```

每次改分都会记日志：谁、什么时候、把哪道题从几分改到几分。

::: tip AI 预评还没接
页面上可能有 AI 预评按钮，当前会提示「未接入」——这是已知状态，不是故障。
:::

## 第 8 步：看统计

进入 **考试统计**，可以看到：

- 大盘概览：参考人次、平均分、及格率
- 分数段分布
- 考生明细与排名
- 逐题正确率 / 难度 / 区分度
- 选项分布与易错项
- 知识点掌握度与薄弱分级

::: tip 数据不对？手动重算
统计基于预计算汇总表，每 10 分钟自动重算一次。
刚改完分想立刻看结果，点**手动重算**即可。
:::

## 第 9 步：发证

配了证书模板且及格的考生会**自动收到证书**。
这在 [证书管理](/guide/certificate) 里可以看到颁发记录。

::: warning 有主观题的卷子会延后发证
必须等阅卷完成，否则证书上的成绩会和最终成绩不一致。
:::
