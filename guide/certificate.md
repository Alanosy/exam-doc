# 证书管理

对应后端服务 `ruoyi-exam-cert` :9218。

## 两类页面

| 页面 | 路径 | 谁看 |
| --- | --- | --- |
| **证书管理**（后台） | `/system/cert` | 管理员 / 教师 |
| **我的证书**（考生端） | `/exam/certs` | 考生 |

后台 Certificate管理页有双 Tab：**证书模板** 与 **颁发记录**。

## 证书模板

### 新建模板

| 字段 | 说明 |
| --- | --- |
| 证书名称 | 例如「前端工程师认证证书」 |
| 副标题 | 可选 |
| 正文内容 | 支持占位符，见下 |
| 颁发机构 | 落款单位 |
| 印章图片 | 上传 PNG（建议透明背景） |
| 背景图片 | 证书底纹 |
| 背景色 | 无背景图时的纯色兜底 |
| **方向** | 横版 / 竖版 |
| 有效期 | 天数；留空则永久有效 |

### 占位符

正文里可以插入这些变量，发证时自动替换：

| 占位符 | 含义 |
| --- | --- |
| `{nickName}` | 考生姓名 |
| `{account}` | 考生账号 |
| `{examName}` | 考试名称 |
| `{score}` | 得分 |
| `{totalScore}` | 试卷总分 |
| `{passScore}` | 及格分 |
| `{certNo}` | 证书编号 |
| `{issueDate}` | 颁发日期 |
| `{expireDate}` | 到期日期 |

**示例正文**：

```text
{nickName} 同学：

  在 {examName} 中取得 {score} 分（总分 {totalScore}，及格分 {passScore}），
  达到认证要求，特发此证。

证书编号：{certNo}
颁发日期：{issueDate}
有效期至：{expireDate}
```

::: tip 编辑时就能预览
后台模板编辑页内置实时预览，用固定样例数据渲染，所见即所得。
保存前先看一眼排版，特别是横竖版的切换。
:::

## 绑定到考试

在发布考试的「及格证书」字段里选择模板。

- **选了模板**：考生及格后自动颁发
- **不选**：不发证书

## 颁发记录

第二个 Tab 显示所有已颁发的证书。

| 操作 | 说明 |
| --- | --- |
| 查看 | 预览证书 |
| **吊销** | **必须填原因**，证书状态变为「已吊销」 |
| **手工补发** | 只需填答卷 ID，成绩由后端自动拉取 |
| 打印 | 调 `window.print()` |

::: warning 有主观题的卷子会延后发证
这是**刻意设计**。必须先等阅卷完成，否则证书上的成绩会低于/不同于最终成绩。
考生拿到证书时分数已经是终局值。
:::

## 考生的「我的证书」

证书墙按卡片展示，每张带有效性标识：

| 状态 | 标识 | 说明 |
| --- | --- | --- |
| 有效 | 绿色 | 在有效期内 |
| 已过期 | 灰色 | 超过 `expireDate` |
| 已吊销 | 红色 | 管理员吊销 |

支持：

- 卡片式浏览
- 详情页查看完整证书
- **打印 / 另存为 PDF**（浏览器打印，选择「另存为 PDF」即可）

## 打印实现

证书用的是 `components/CertificatePaper.vue`，内置 `@media print` 样式——
打印时**只保留证书纸本身**，页眉页脚、侧边栏、按钮全部隐藏。

统一的打印入口就是浏览器原生的 `window.print()`。

复用位置：

```text
views/system/cert/index.vue      后台预览
views/exam/certs/index.vue       我的证书
views/exam/records/detail.vue    答题记录里的证书
views/exam/answer/index.vue      考完直接展示
```

## 选型建议

| 场景 | 建议配置 |
| --- | --- |
| 学历教育期末证明 | 竖版，含学校印章，永久有效 |
| 职业资格认证 | 横版，含证书编号，**设 2~3 年有效期** |
| 内部培训达标 | 简洁版，背景色即可，永久有效 |
| 竞赛获奖 | 突出排名信息，横版荣誉证书样式 |

::: tip 有效期要不要设
设了有效期，考生就得定期重新认证——这对**技能类认证**（技术、安全规范）是合理的，
因为知识会过期。但对**学历证明类**通常设永久有效。
:::

## 常见问题

### 及格了但没收到证书

按顺序排查：

1. 考试有没有绑定证书模板（没绑就不发）
2. 分数是否真的达到及格分
3. **有没有未阅完的主观题**——有就要等
4. `exam-cert` 服务是否在运行

### 证书上的成绩和后台看到的不一致

说明证书是先发的，之后分数被改过（rescore）。
砚考的设计已经避免了这个情况（延后发证），如果遇到请提 Issue。

### 想批量发证

及格后系统自动发，不需要手工触发。
只有补历史数据才用「手工补发」，且一次填一个答卷 ID。

### 证书编号规则

由后端生成，保证唯一。如果需要对接外部系统验证，可以把 `{certNo}` 输出到外部。
