# 试卷与组卷

试卷是「题目的编排」。对应后端服务 `ruoyi-exam-paper` :9212。

::: tip 先确认
进入本页前请先在 [题库与试题](/guide/question-bank) 里建好题库和题目——组卷是从题库里挑题，凭空造不出卷子。
:::

## 进入组卷

**试卷管理 → 新增**，或直接点现有试卷的「编辑」。组卷页是一个两步流程（Element Steps）。

## 方式一：随机抽题

适合想让**每个学生卷子不一样**的场景（防止互相抄）。

### 配置一条规则

| 维度 | 说明 |
| --- | --- |
| 题库 | 从哪个题库抽（不选则全库） |
| 题型 | 单选 / 多选 / 判断 / 填空… |
| 难度 | easy / medium / hard |
| 抽取数量 | 要几道 |
| 单题分值 | 每道题多少分 |

可以**添加多条规则**，例如：

```text
规则一：JavaScript 题库 · 单选 · 中等 · 5 道 · 每题 4 分   = 20 分
规则二：JavaScript 题库 · 多选 · 困难 · 3 道 · 每题 6 分   = 18 分
规则三：JavaScript 题库 · 简答 · 任意 · 2 道 · 每题 15 分  = 30 分
                                                    合计 68 分
```

点右侧的抽题按钮（`MagicStick` 图标）即可按规则抽题并预览。

### 候选不足时会提示

::: warning 提前告诉你，而不是开考才发现
题库里符合条件的题不够时会提示，例如：

> 「JavaScript 题库」中「困难」难度的「多选题」只有 2 道，不足需要抽取的 3 道

这时你有三个选择：

1. 放宽条件（比如难度改为「中等及以上」）
2. 先去补题
3. 减少抽取数量
:::

### 规则可保存复用

配好的规则会随试卷保存。下次在同样的题库里出卷可以直接复用。

## 方式二：手工选题

适合「我知道要考哪几道题」的场景（比如老师精选题）。

- 支持**跨分页勾选**——翻页时已选不会被清掉
- 支持拖拽排序
- 支持改单题分值
- 支持批量应用默认分值

两者也可以**混用**：先随机抽一批，再手工增补几道。

## 填写试卷信息

第二步填写：

### 基本信息

| 字段 | 说明 |
| --- | --- |
| 试卷名称 | |
| 总分 | 默认按题目分值累加，**可以手动改**（比如凑整 100 分） |
| 及格分 | 达到才发证书、才计为及格 |
| 状态 | 草稿 / 就绪 / 归档 |
| 可见性 | 私有 / 公开 |

::: tip 总分可以不等于题目分值之和
这是特意留的口子。比如抽题抽出来 98 分，你想凑成 100 分，直接改总分即可，
不需要硬凑题目。但要注意**及格分与实际分值的比例关系**。
:::

### 展示策略

| 开关 | 效果 | 什么时候开 |
| --- | --- | --- |
| **题目乱序** | 每个学生看到的题目顺序不同 | 防抄袭，建议开 |
| **选项乱序** | 每个学生看到的选项顺序不同 | 防抄袭，建议开 |

::: warning 论述题、材料题不要开题目乱序
如果题目之间有承接关系（比如材料题、阅读理解），乱序会让考生看不懂。
这种情况请关闭题目乱序，或改用固定卷。
:::

### 判分策略

| 开关 | 效果 | 建议 |
| --- | --- | --- |
| **自动判分** | 客观题交卷即出分 | 默认开 |
| **部分得分** | 多选题漏选时按比例给分 | 建议开 |
| **答错扣分** | 答错倒扣分 | **慎用** |

::: danger 答错扣分要慎重
开启后答错会倒扣，可能导致负分。
国内多数考试习惯不倒扣；只有在淘汰型选拔考试里才建议开。

如果开了「部分得分」，还会要求配 **`partialScoreRate`**（部分得分比例），
典型值是 0.5（漏选一半得一半分）。
:::

## 保存

组卷页有两个保存按钮：

| 按钮 | 效果 |
| --- | --- |
| 保存草稿 | 状态 draft，还不能发布考试 |
| 保存并就绪 | 状态 ready，可以发布考试了 |

::: warning 保存是全量覆盖
每次保存，`paper_question`（试卷-题目关联）会按当前提交的明细**全量覆盖**——
你在这一版里删掉的题不会被保留。

如果只想改分值不想动明细，也要完整提交整份明细列表。
:::

## 常见问题

### 改了题库里的题，已发布的考试受影响吗

**分情况**：

| 场景 | 是否受影响 |
| --- | --- |
| 考试还没人答题 | 会。因为还没抓快照 |
| 已经有考生开考 | 不会。开考瞬间抓了试卷快照 |

稳妥做法：**发布前定稿题库**。

### 可以一张卷子发布多场考试吗

可以，而且推荐这么做。同一份试卷给 A 班、B 班各发一场考试，各自独立统计数据。

### 我没看到「随机抽题」Tab

检查有没有建过题库分类、题库里有没有正常状态的题。
全部归档的题库不参与抽题。
