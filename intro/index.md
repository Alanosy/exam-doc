# 砚考

砚考是一款**开箱即用**的在线考试系统，覆盖 **出题 → 组卷 → 考试 → 监考 → 阅卷 → 统计 → 发证 → 错题巩固** 的完整闭环，内置学生、教师、管理员三种角色。

## 它把几件麻烦事做实了

| 麻烦事 | 砚考的做法 |
| --- | --- |
| **组卷要一道道挑** | 除手工选题外，可按「题库 + 题型 + 难度 + 分值」配一条随机抽题规则，规则能保存复用，候选不足时提前提示 |
| **防作弊形同虚设** | 切屏离屏、窗口失焦、复制剪切粘贴、右键、退出全屏、多标签页、开发者工具等 13 类行为全程记录并计数，摄像头定时抓拍留证；达到上限**由服务端判定强制交卷**，改前端绕不过去，同时对考生透明展示规则与已用次数 |
| **判分要干等** | 客观题交卷即自动出分（区分正确 / 半对 / 错误三态），主观题按「考试 → 答卷 → 逐题」三级人工阅卷，每次改分留审计日志 |
| **考完拿不到数** | 分数段分布、逐题正确率 / 难度 / 区分度、选项分布与易错项、知识点掌握度与薄弱分级；汇总表每 10 分钟定时重算兜底，也可手动重算 |
| **结果没沉淀** | 及格自动颁发证书（模板支持占位符、印章、背景图、横竖版与有效期），答错和半对的题自动进错题本，可反复重练、记笔记、标记掌握 |
| **答题怕掉线** | 逐题自动保存、中途退出可断点续答、倒计时归零自动交卷（前端主动提交 + 后端定时兜底双保险），重复交卷幂等 |

## 三种角色

```text
管理员 ── 租户、用户、角色菜单、字典参数、AI 模型配置、系统监控
   │
教师 ──── 建题库 / 出题 / 组卷 / 发布考试 / 监考 / 阅卷 / 看统计
   │
学生 ──── 考试中心 / 在线答题 / 考试记录 / 错题本 / 我的证书
```

## 关于 AI

AI 能力正在接入中：

- Python Agent（`ruoyi-exam-agent`）已完成**出题、阅卷、推荐、试卷分析**四类能力
- Java 侧网关与 AI 模型配置表已就绪

::: tip AI 尚未接线
Java 与 Python 之间的**接线工作进行中**，当前 AI 阅卷会返回「未接入」。这是已知状态，不是故障。
详情见 [考试微服务总览 — AI 服务](/backend/exam/overview#ai-服务-ruoyi-exam-ai-9220)。
:::
