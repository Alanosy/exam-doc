# 功能截图

以下为砚考实际运行界面。

## 管理端

### 题库与试题管理

题库按分类树组织，支持可见性与三态管理；试题支持富文本题干、9 种题型与 Excel 导入。

![题库与试题管理](http://bucket.alan.org.cn/blog/2026/10/02/15-22-35-c0e20243086e1f31b51949fd262cd167-5b1234.png)

### 试卷组卷

支持手工选题与按规则随机抽题，组卷后可预览试卷结构。

![试卷组卷](http://bucket.alan.org.cn/blog/2026/10/02/16-54-13-8c24c3c3b11b2c4beb21e4b752418b61-55bd73.png)

### 考试管理

两步式考试配置：基本信息 + 参加方式与考试规则。

![考试管理](http://bucket.alan.org.cn/blog/2026/10/02/16-56-09-38f4c6ee221536f6a158c42b27c5d99c-347b46.png)

## 阅卷与监考

### 阅卷管理

按「考试 → 答卷 → 逐题」三级组织，支持改分留痕与 AI 预评。

![阅卷管理](http://bucket.alan.org.cn/blog/2026/10/02/17-26-29-120c709884c644ecff863fae9109b945-c76290.png)

### 监考中心

实时查看监考会话、风险概览、事件流水与摄像头抓拍墙。

![监考中心](http://bucket.alan.org.cn/blog/2026/10/02/17-25-22-aef85c1edcdfae86bf9e94103fd9ecaa-06b4cf.png)

## 统计与证书

### 考试统计

分数段分布、逐题正确率 / 难度 / 区分度、选项分布与知识点掌握度。

![考试统计](http://bucket.alan.org.cn/blog/2026/10/02/17-24-50-42d47142c854b1612a8b4c3545e11aa5-46de92.png)

### 证书

模板支持占位符、印章、背景图、横竖版与有效期；及格自动颁发。

## 考生端

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 加入考试 | `/exam/join/:code` | 扫码直入，独立整页无侧边栏 |
| 考试中心 | `/exam/center` | 待考 / 进行中 / 已结束分类展示 |
| 考试须知 | `/exam/brief/:examId` | 展示规则、防作弊说明、入场时间窗 |
| 在线答题 | `/exam/answer/:recordId` | 答题主页面，含倒计时与监考状态卡 |
| 考试记录 | `/exam/records` | 历史考试列表与筛选 |
| 答题详情 | `/exam/record/:recordId` | 逐题回看作答、正确答案、解析与得分 |
| 我的证书 | `/exam/certs` | 证书墙，区分有效 / 已过期 / 已吊销 |
| 错题本 | `/exam/wrong` | 按来源分组，支持重练、笔记、标记掌握 |
