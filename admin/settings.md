# 系统设置

系统设置影响整个机构的所有用户，通常由超级管理员或机构管理员维护。

## 基础设置

| 项目 | 说明 |
| --- | --- |
| 机构名称 | 显示在页头、报告页脚、导出文件 |
| 机构 Logo | 建议 200×60 PNG，透明底 |
| 默认语言 | 简体中文 / 繁体中文 / English |
| 时区 | 影响所有考试时间，上线初期务必确认 |
| 品牌域名 | 私有化部署可绑定自有域名 |

::: warning 修改时区会影响已排期的考试
时区变更会重新计算所有考试的开放时间。
只读查看已有考试排期的情况下不要动这一项。
:::

## 登录与安全

| 项目 | 推荐值 |
| --- | --- |
| 密码最小长度 | 8 |
| 密码复杂度 | 字母 + 数字 |
| 密码有效期 | 90 天（政企）/ 关闭（高校可选） |
| 登录失败锁定 | 5 次锁定 30 分钟 |
| 双因素认证 | 管理员强制开启 |
| 会话超时 | 4 小时（可根据考场时长放宽） |
| 允许同时在线设备数 | 考试期间建议设为 1 |

### 单点登录

支持 CAS、OAuth2、SAML 2.0、LDAP / AD。
配置路径：**系统设置 → 集成 → 单点登录**。

需要填写的通用字段：服务地址、客户端 ID / 密钥、用户属性映射（学号/工号、姓名、组织）。
配置页提供「测试连接」按钮，建议先测试再启用。

## 考试默认值

为新建考试预设默认值，减少重复配置：

- 默认答题时长
- 默认防作弊策略（可按考试类型分别设定）
- 默认成绩发布方式
- 默认允许迟到分钟数
- 默认答案保存间隔

## 监考与隐私

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 人脸底片留存 | 考后 90 天自动删除 | 可改为 30 / 180 天或永久 |
| 抓拍影像留存 | 考后 90 天 | 同上 |
| 屏幕录制留存 | 考后 30 天 | 录制占用存储较大 |
| 环境音留存 | 不留存 | 默认只作实时检测不落盘 |
| 监考影像访问审批 | 关闭 | 开启后查看影像需二次审批 |

::: tip 合规提示
若机构所在地对个人生物识别信息有强制性规定，请在开启人脸核验前
完成个人信息保护影响评估，并在考试说明中告知考生。
:::

## 阅卷设置

| 项目 | 说明 |
| --- | --- |
| 双评容差 | 默认分值的 10% |
| AI 评分建议 | 默认关闭，需显式开启 |
| 评分最小粒度 | 1 分 / 0.5 分 |
| 允许查看他人评分 | 默认关闭，避免评分相互干扰 |
| 单题评阅最短用时 | 防「秒评」，默认 5 秒 |

## 通知设置

### 渠道

- 站内信（始终可用）
- 短信（需配置短信服务商）
- 邮件（需配置 SMTP）
- 企业微信 / 钉钉 / 飞书机器人

### 触发时机

| 事件 | 可通知对象 |
| --- | --- |
| 考试发布 | 考生、监考员 |
| 考前提醒 | 考生 |
| 考试开始 | 监考员 |
| 阅卷任务分配 | 阅卷员 |
| 阅卷超时未完 | 阅卷员、考务管理员 |
| 成绩发布 | 考生、教师 |
| 违纪认定 | 考生、考务管理员 |

模板支持变量：`{姓名}` `{考试名称}` `{时间}` `{链接}` `{得分}`。

## 存储与容量

**系统设置 → 资源** 查看：

- 已用存储 / 配额
- 题库题目总数
- 近 12 个月考试场次
- 影像文件占用（通常是最主要的存储开销）

清理建议：

- 定期归档超过保留期的影像
- 导出并删除历史考试的答题附件
- 已归档题库可只保留结构不保留素材

## 数据备份

| 项目 | 建议 |
| --- | --- |
| 备份频率 | 每日全量 + 每小时增量 |
| 备份保留 | 30 天 |
| 异地备份 | 开启 |
| 恢复演练 | 每季度一次 |

私有化部署可在 [部署文档](/admin/deployment) 中找到备份脚本示例。

## 审计日志

**系统管理 → 审计日志**，支持按以下条件检索：

- 操作人、操作类型、时间范围
- 涉及对象（考试 ID、用户 ID）
- 操作结果（成功 / 失败）

敏感操作（成绩导出、监考影像查看、权限变更、成绩更正）会单独高亮。
日志不可删除，保留期默认 180 天，可在安全设置中延长。

## 常见问题

**改了机构 Logo 没生效？**
浏览器缓存导致，强制刷新（Cmd/Ctrl + Shift + R）即可。

**短信发不出去？**
检查短信服务商配置与余额，并在「通知设置 → 发送记录」中查看失败原因。
