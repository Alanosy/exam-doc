# 题库管理

题库是砚考的数据底座。题库建得规范，后面的组卷、阅卷、分析都会顺畅很多。

## 创建题库

进入 **题库管理 → 我的题库 → 新建题库**：

| 字段 | 说明 |
| --- | --- |
| 题库名称 | 建议包含学期与课程，如 `2026 春 · 数据结构` |
| 所属学科 | 用于平台级统计与模板匹配 |
| 负责人 | 默认拥有该题库的全部权限 |
| 可见范围 | 私有 / 本机构 / 指定组织节点 |
| 审核流程 | 开启后，新题需经审核才可被组卷引用 |

::: tip 一个课程建一个题库
不要按「章节」或「考试」建库，那样会造成题目割裂与重复。
推荐粒度：**一门课程一个题库**，用知识点标签做内部分类。
:::

## 知识点目录

在题库详情页切换到「知识点」标签，可以：

- 手工逐级添加
- 从平台预设模板导入（覆盖 K12、本科公共课、部分职业资格）
- 上传 Excel 批量导入（两列：父节点、子节点）

知识点树的深度建议控制在 2—3 层，过深会导致分析报表难以阅读。

## 支持的题型

| 题型 | 判分方式 | 备注 |
| --- | --- | --- |
| 单选题 | 自动 | 支持选项乱序 |
| 多选题 | 自动 | 支持「少选得部分分」规则 |
| 不定项选择题 | 自动 | 题干不提示单选还是多选 |
| 判断题 | 自动 | |
| 填空题 | 自动 | 支持多空、等价答案、大小写与全半角容错 |
| 简答题 | 人工 | 支持关键词辅助初筛 |
| 论述题 | 人工 | 建议配置评分要点 |
| 计算题 | 人工 / 半自动 | 支持按步骤给分 |
| 编程题 | 自动 | 多语言判题，支持自定义测试用例 |
| 材料题（大题） | 人工 | 一个题干下挂多个小题，小题可为任意题型 |
| 排序题 | 自动 | |
| 连线题 | 自动 | |

## 录入方式

### 单题录入

适合精编题目。编辑器支持：

- 富文本（加粗、列表、表格、图片、附件）
- 行内与独立公式：输入 `$E=mc^2$` 或 `$$\int_0^1 x^2 dx$$`
- 音频（外语听力题）
- 选项乱序开关、答案解析、命题意图备注

### Excel 模板导入

1. 在题库页点击「批量导入 → 下载模板」
2. 按模板列填写，每行一道题
3. 上传后系统会做格式校验并给出**预览**，可逐行修正
4. 确认无误后提交

常见校验错误：

| 报错 | 原因 |
| --- | --- |
| 题型未识别 | 模板里题型列填写了非标准名称 |
| 答案数量不匹配 | 填空题的空数与题干中 `__` 数量不一致 |
| 知识点不存在 | 知识点名称与目录中已有项不一致，需先建目录 |

### 文本批量导入

适合从旧系统迁移。语法示例：

```text
【单选】【力学/牛顿运动定律】【难度0.7】
关于惯性，下列说法正确的是：
A. 物体运动越快惯性越大
B. 静止的物体没有惯性
C. 惯性大小只与质量有关
D. 失重状态下惯性消失
答案：C
解析：惯性是物体的固有属性，仅由质量决定。
```

一次最多粘贴 200 道，系统会自动切分并生成预览。

### API 导入

有自研题库系统的机构，可通过 [开放 API](/api/) 批量推送题目。

## 查重与质量控制

保存题目时，系统会自动做**相似度检测**：

- 题干文本相似度 > 85% → 提示「疑似重复」，可查看对比
- 选项集合完全一致 → 直接拦截
- 同一知识点下难度与考查角度高度雷同 → 在质量报告中标注

题库详情页的「质量报告」会给出：

| 指标 | 健康区间 |
| --- | --- |
| 题目总量 | 建议 ≥ 10 × 单卷题量 |
| 知识点覆盖 | 无零题目知识点 |
| 难度分布 | 0.3—0.8 区间占比 ≥ 70% |
| 重复率 | < 3% |
| 未审核题目占比 | < 10% |

## 版本与变更留痕

题目被修改后：

- 已在**进行中 / 已结束**的考试中：沿用旧版本，不影响既有成绩
- 在**未开始**的考试中：可手动选择「同步为新版本」或「保持旧版本」
- 所有修改记录可在题目详情页「变更历史」中查看与回滚

::: warning 谨慎修改被高频引用的题目
修改一道题会影响所有引用它的试卷。
若只是修正错别字，建议保留原意；若改变了答案，务必同步检查已排期的考试。
:::

## 权限

| 角色 | 题库权限 |
| --- | --- |
| 创建者 | 全部权限（增删改、授权他人） |
| 协作教师 | 增、改、提交审核 |
| 审核员 | 审核通过 / 打回 |
| 只读成员 | 查看与引用 |

详见 [用户与角色](/admin/users-roles)。

## 导出与归档

- 支持导出为 Excel、Word（可直接打印成纸质卷）、JSON
- 学期结束可对题库做「归档」，归档后不可再修改，但仍可被引用与统计
