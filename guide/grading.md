# 阅卷与复核

砚考把阅卷拆成「客观题机器判 + 主观题人工评 + 争议卷仲裁」三段，每段都有进度追踪。

## 判分流程总览

```text
考生交卷
   ↓
客观题自动判分（即时）
   ↓
主观题任务分配 → 教师评阅 → 复核 / 仲裁
   ↓
成绩合成 → 教师确认 → 发布成绩
```

## 客观题自动判分

交卷瞬间完成，规则如下：

| 题型 | 判分规则 |
| --- | --- |
| 单选题 | 完全一致得分 |
| 多选题 | 全对得满分；开启「少选部分分」时按选中正确项比例给分；含错误项得 0 |
| 判断题 | 完全一致得分 |
| 填空题 | 逐空比对，支持等价答案、忽略大小写/全半角/首尾空格 |
| 排序题 | 完全一致或按相邻对正确率给分 |
| 连线题 | 按正确连线数比例给分 |
| 编程题 | 多测试用例判分，通过率 × 分值 |

::: tip 填空题的等价答案
在题目编辑页的「答案」区域可以添加多个等价答案，
例如 `π/2`、`0.5π`、`1.5708` 都可判定正确。
系统还会自动做数值容差判断（默认 ±1e-6，可配置）。
:::

## 主观题任务分配

进入 **阅卷中心 → 创建阅卷任务**：

| 分配方式 | 说明 | 适用 |
| --- | --- | --- |
| 按题分配 | 每位教师负责若干道题目 | 教师分工明确（推荐） |
| 按人分配 | 每位教师负责若干考生整卷 | 需要整体把握的论述题 |
| 混合分配 | 客观题按题、主观题按人 | 大规模考试 |
| 分段抽查 | 只抽取一部分试卷评阅 | 练习与模拟考 |

### 双评与仲裁

开启双评后，同一道题由两位教师独立评阅：

```text
两位评分差值 ≤ 容差（默认 分值的 10%）→ 取平均
两位评分差值 > 容差               → 自动进入仲裁队列
```

仲裁由第三人给出最终分，且仲裁结果会反馈给原评阅教师，用于校准标准。

::: tip 什么时候开双评
- 期末、认证、招聘等高利害考试：**建议开启**
- 日常测验：单人评阅即可，开启双评会让阅卷工作量翻倍
:::

## 评阅界面

按题分配模式下，界面是这样的：

```text
┌─────────────────────────────────────────────────┐
│ 第 3 题（计算题，15 分）        进度 42/248       │
├─────────────────────────────────────────────────┤
│ 学生作答：                                       │
│   [作答图片 / 文本]                              │
├─────────────────────────────────────────────────┤
│ 参考答案与评分要点：                             │
│   (1) 受力分析正确 —— 5 分                       │
│   (2) 列出运动方程 —— 5 分                       │
│   (3) 计算结果正确 —— 5 分                       │
├─────────────────────────────────────────────────┤
│ 得分：[  ]  [按要点快捷给分]  [标记待复核]  [下一份]│
└─────────────────────────────────────────────────┘
```

常用能力：

- **按要点快捷给分**：点击评分要点即可累加对应分值
- **分步骤给分**：计算题可逐步骤打分，自动求和
- **常用评语**：预置评语一键插入，如「步骤完整但结果有误」
- **AI 评分建议**：仅作参考，需教师确认后才写入
- **标记待复核**：交给教研组长或仲裁人处理
- **回退上一份**：发现评错了可以改，修改会留痕

::: warning 关于 AI 评分建议
AI 给出的分数**永远只是一条建议**。砚考的设计原则是：
AI 不直接产生最终成绩，任何评分都必须经过教师确认。
可在 [系统设置](/admin/settings) 中整体关闭该功能。
:::

## 进度看板

阅卷中心顶部实时展示：

| 指标 | 说明 |
| --- | --- |
| 总份数 / 已评 | 整体进度条 |
| 各教师进度 | 谁落后一目了然 |
| 平均分曲线 | 评到一半时若发现均分异常，可及时校准标准 |
| 待复核数 | 争议卷积压情况 |
| 预计完成时间 | 按当前速度推算 |

若某位教师的评分均值显著偏离整体（超过 1.5 个标准差），
系统会提示「评分标准可能存在偏差」，建议教研组长介入校准。

## 复核与仲裁

### 复核

三种触发方式：

1. 教师评阅时点击「标记待复核」
2. 系统自动标记（双评差值超容差、AI 建议与人工分差异大）
3. 学生查卷申请被受理

复核人在「待复核」列表中处理，可以维持原分或修改，修改必须填写理由。

### 仲裁

仅双评模式下存在。仲裁人看到两位教师的评分与评语，**直接给出最终分**，
该分数即为最终成绩，不可再被修改（除非走成绩更正流程）。

## 成绩合成与确认

所有题目评完后：

```text
总分 = Σ 各题得分
```

在「成绩合成」页面可以：

- 查看分数分布直方图，确认无异常
- 执行**加分/扣分规则**（如「卷面分 × 0.7 + 平时分 × 0.3」）
- 处理缺考、缓考、违纪三类特殊状态
- 设定及格线并查看及格率

确认无误后点击「提交成绩」，进入 **待发布** 状态。

## 成绩更正

成绩发布后如需修改：

1. 在成绩列表中找到该生 → 「申请更正」
2. 填写更正原因，上传佐证材料
3. 由具有「成绩管理」权限的角色审批
4. 审批通过后生效，**原成绩与新成绩均永久留痕**

更正记录会出现在审计日志中，无法删除。

## 学生查卷

若开启了「允许查卷」：

```text
学生提交查卷申请 → 教师在规定时限内处理 → 反馈结论（维持/变更）
```

查卷期间成绩状态不变，学生可继续查看原成绩。
查卷结论若导致分数变化，走上述成绩更正流程。

## 常见问题

**主观题太多，阅卷来不及？**
可以在创建阅卷任务时选择「按题分配 + 多位教师」，
并为分值较低的题目开启「AI 建议分 + 教师快速确认」模式。

**能导出阅卷明细吗？**
可以。阅卷中心 → 导出，支持 Excel 明细（每位教师、每道题的评分与用时）与 PDF 存档。

**评错了想改怎么办？**
成绩发布前可自由修改；发布后需走成绩更正流程。所有修改都会留痕。
