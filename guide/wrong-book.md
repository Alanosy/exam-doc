# 错题本

对应后端服务 `ruoyi-exam-practice` :9217（对外前缀 `/practice`，内部接口是 `/wrong/*`）。

考生端入口：**错题本**（路径 `/exam/wrong`）。

## 什么题会进错题本

交卷后由系统**自动收录**，不需要手工操作：

| 判分结果 | 是否进错题本 |
| --- | :---: |
| 正确 | ❌ |
| **半对**（多选题漏选、填空部分空答对） | ✅ |
| 错误 | ✅ |

::: tip 为什么「半对」也要进
多选题漏选说明「知道但不全」，是典型的知识薄弱环节。
完全不会的题反而可能不涉及考生的知识范围（比如超纲题）。

两者都进去，等你来判断要不要练。
:::

::: warning 客观题才有「自动收录」
主观题的得分由老师人工判定，是否算错取决于老师给多少分，所以不进入自动收录逻辑。
:::

## 概览

错题本首页显示：

- 错题总数
- 已掌握 / 未掌握数量
- 按来源分组列表

## 按来源分组

错题会按**来源**（哪场考试产生的）分组，方便你好好准备补考、期中这类明确目标的复习。

```text
前端期末考试        12 道未掌握
Java 认证模拟        5 道未掌握
随堂测验三           3 道未掌握
```

点进去只看这一组的错题。

## 重练

点某道题进入练习：

1. 展示题干与选项（**不展示正确答案**——先让你想一遍）
2. 作答后提交
3. **即时判分**，并展示正确答案与解析
4. 判对了可以标记掌握

每次重做都会记一条 `wrong_review_record`，保留完整历史。

::: tip 为什么不直接给答案
直接看答案会产生「我本来就会」的错觉。
先作答再看反馈，才能真正检验是否掌握。
:::

## 笔记

每道错题可以记**学习笔记**，记下自己的思路误区、需要注意的点。

用好这个功能，错题本就从「题目集合」变成「个人知识漏洞手册」。

## 状态管理

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| 未掌握 `NOT_MASTER` | 默认状态 | — |
| 已掌握 `MASTERED` | 学会后标记 | 移出复习列表（可恢复） |
| 已忽略 `IGNORED` | 不想练（超纲、题目有争议） | 隐藏（可恢复） |

「已掌握」和「已忽略」都**不是删除**，随时可以恢复，数据安全。

## 查看历史

每道题可以查看**每次重做的记录**：

```text
第一次：错 — 答了 B
第二次：错 — 答了 C
第三次：对 — 答了 A  ✓
```

知道自己是怎么一步步学会的，比单纯知道结果更有价值。

## 数据流向

```text
考生交卷
    │ answer 服务判分
    │ （触发）writeWrongQuestions
    ▼
exam-practice (9217)
    │ 写 wrong_question（引用 question_id，不复制题目）
    ▼
考生端错题本展示
```

::: tip 错题是引用，不是拷贝
`wrong_question` 记的是「谁错了哪道题」，**不复制题目本身**。
所以老师改进了题目解析，考生端会同步看到最新版本。
:::

## 与统计里的「错题」是两回事

| | 错题本 | 统计分析 |
| --- | --- | --- |
| 视角 | 单个考生 | 全班集体 |
| 目的 | 个人复习 | 教学改进 |
| 数据来源 | 本人答卷 | 全部答卷聚合 |

如果你只想看自己的薄弱环节，用错题本；
如果你是老师想看班上普遍错在哪，用 [成绩与学情分析](/guide/analytics)。

## 常见问题

### 错题数量不对

检查：

1. 主观题不进错题本（人工判分不算）
2. 「已忽略」的题默认是隐藏的，筛选里要勾上
3. 「已掌握」同样需要筛选

### 想删除某条错题

系统不提供物理删除，只能标记「已忽略」或「已掌握」。
这是有意的——错题记录是有价值的学情数据。

### 老师想知道全班错题情况

管理端的错题维护页面**尚未实现**，当前错题能力集中在考生端。
如需全班视角，请用 [成绩与学情分析](/guide/analytics) 里的「易错项」和「知识点薄弱分析」。

### 基于题库/章节的刷题练习

还没有。当前只能练习「自己错过的题」，不能主动从题库挑题刷——这个功能在规划中。
